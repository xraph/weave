---
title: Extension System
description: Weave lifecycle hooks for ingestion, retrieval, collection, delete, reindex and shutdown events.
---

Weave's extension system lets you attach callbacks to engine events. Use it for metrics, tracing, audit trails, alerting or any other side effect, without touching the pipeline itself.

## Extension interface

Every extension must implement the base `Extension` interface:

```go
// Package ext
type Extension interface {
    Name() string // unique human-readable name
}
```

Beyond `Name()`, an extension implements only the hook interfaces it cares about. The engine type-asserts each extension against every hook interface when you register it.

The `ext` and `plugins` packages declare the same interfaces. `engine.WithExtension` takes an `ext.Extension` and the Forge extension's `WithExtension` takes a `plugins.Extension`, but since both are just `Name() string`, the same value works for either.

## Registering extensions

```go
eng, err := engine.New(
    engine.WithStore(st),
    engine.WithVectorStore(vs),
    engine.WithEmbedder(emb),
    engine.WithChunker(chunker.NewRecursiveChunker()),
    engine.WithExtension(metricsExt),
    engine.WithExtension(auditExt), // repeatable
)
```

Hooks fire in registration order. In a Forge app, pass them with `extension.WithExtension(x)`.

## All hook interfaces

### Collection hooks

```go
// Called after a collection is created.
type CollectionCreated interface {
    OnCollectionCreated(ctx context.Context, col *collection.Collection) error
}

// Called after a collection is deleted.
type CollectionDeleted interface {
    OnCollectionDeleted(ctx context.Context, colID id.CollectionID) error
}
```

### Ingestion hooks

```go
// Called after the document row is created, before loading and chunking.
type IngestStarted interface {
    OnIngestStarted(ctx context.Context, colID id.CollectionID, docs []*document.Document) error
}

// Called after documents are chunked.
type IngestChunked interface {
    OnIngestChunked(ctx context.Context, chunks []*chunk.Chunk) error
}

// Called after chunks are embedded.
type IngestEmbedded interface {
    OnIngestEmbedded(ctx context.Context, chunks []*chunk.Chunk) error
}

// Called when ingestion completes successfully.
type IngestCompleted interface {
    OnIngestCompleted(ctx context.Context, colID id.CollectionID, docCount, chunkCount int, elapsed time.Duration) error
}

// Called when ingestion fails.
type IngestFailed interface {
    OnIngestFailed(ctx context.Context, colID id.CollectionID, err error) error
}
```

### Retrieval hooks

```go
// Called when a retrieval query starts.
type RetrievalStarted interface {
    OnRetrievalStarted(ctx context.Context, colID id.CollectionID, query string) error
}

// Called when retrieval completes successfully.
type RetrievalCompleted interface {
    OnRetrievalCompleted(ctx context.Context, colID id.CollectionID, resultCount int, elapsed time.Duration) error
}

// Called when retrieval fails.
type RetrievalFailed interface {
    OnRetrievalFailed(ctx context.Context, colID id.CollectionID, err error) error
}
```

### Document hooks

```go
// Called after a document is deleted.
type DocumentDeleted interface {
    OnDocumentDeleted(ctx context.Context, docID id.DocumentID) error
}
```

### Reindex hooks

```go
// Called when a collection reindex starts.
type ReindexStarted interface {
    OnReindexStarted(ctx context.Context, colID id.CollectionID) error
}

// Called when a collection reindex completes.
type ReindexCompleted interface {
    OnReindexCompleted(ctx context.Context, colID id.CollectionID, elapsed time.Duration) error
}
```

### Shutdown hook

```go
// Called by engine.Stop, before the store is closed.
type Shutdown interface {
    OnShutdown(ctx context.Context) error
}
```

## Implementing an extension

Implement only the interfaces for the events you need:

```go
type AuditExtension struct {
    logger *slog.Logger
}

func (e *AuditExtension) Name() string { return "audit" }

func (e *AuditExtension) OnIngestCompleted(
    ctx context.Context,
    colID id.CollectionID,
    docCount, chunkCount int,
    elapsed time.Duration,
) error {
    e.logger.Info("ingest completed",
        slog.String("collection_id", colID.String()),
        slog.Int("docs", docCount),
        slog.Int("chunks", chunkCount),
        slog.Duration("elapsed", elapsed),
    )
    return nil
}

func (e *AuditExtension) OnIngestFailed(
    ctx context.Context,
    colID id.CollectionID,
    err error,
) error {
    e.logger.Error("ingest failed",
        slog.String("collection_id", colID.String()),
        slog.String("error", err.Error()),
    )
    return nil
}
```

## Error handling

Hook errors never reach the caller. If a hook returns an error, the registry logs it at warn level (with the hook and extension name) through the engine's logger and carries on with the next extension and the operation itself. Hooks run synchronously on the calling goroutine, so a slow hook slows `Ingest` or `Retrieve` down.

`OnIngestFailed` and `OnRetrievalFailed` receive the error for observability. They can't change what the caller gets back.

## Built-in extensions

`observability.NewMetricsExtension()` counts events, see [observability](/docs/subsystems/observability).

`audit_hook` (package `audithook`) turns every hook except `IngestChunked`, `IngestEmbedded` and `Shutdown` into an `AuditEvent` and hands it to a `Recorder`:

```go
import audithook "github.com/xraph/weave/audit_hook"

audit := audithook.New(audithook.RecorderFunc(
    func(ctx context.Context, ev *audithook.AuditEvent) error {
        log.Printf("%s %s %s", ev.Action, ev.ResourceID, ev.Outcome)
        return nil
    },
))
```

The `Recorder` interface has the same shape as Chronicle's emitter, so you can bridge it to [Chronicle](https://github.com/xraph/chronicle) without Weave importing it. `audithook.WithActions(audithook.ActionIngestFailed, ...)` limits which actions get recorded, and failures are recorded with `SeverityCritical`.
