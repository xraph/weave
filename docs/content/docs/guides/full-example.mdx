This guide builds a whole RAG loop on PostgreSQL, pgvector and the OpenAI embedder. The sections below are one `main.go`, in order.

## 0. Prepare the database

You need PostgreSQL with the pgvector extension available, 0.8.0 or later if you can (the `pgvector/pgvector:pg17` image works). Both migrations run from `main` below, so there's no SQL to run by hand. The [pgvector](/docs/stores/pgvector) page lists what they create.

## 1. Set up the engine

```go
package main

import (
    "context"
    "errors"
    "fmt"
    "log"
    "os"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"

    "github.com/xraph/weave"
    "github.com/xraph/weave/chunker"
    "github.com/xraph/weave/collection"
    "github.com/xraph/weave/embedder"
    "github.com/xraph/weave/engine"
    "github.com/xraph/weave/store/postgres"
    "github.com/xraph/weave/vectorstore/pgvector"
)

func main() {
    ctx := context.Background()

    pgdb := pgdriver.New()
    if err := pgdb.Open(ctx, os.Getenv("DATABASE_URL")); err != nil {
        log.Fatal(err)
    }
    db, err := grove.Open(pgdb)
    if err != nil {
        log.Fatal(err)
    }

    st := postgres.New(db)
    if err := st.Migrate(ctx); err != nil {
        log.Fatal("migrate: ", err)
    }
    emb := embedder.NewOpenAIEmbedder(os.Getenv("OPENAI_API_KEY"))
    if err := pgvector.Migrate(ctx, db, emb.Dimensions()); err != nil {
        log.Fatal("migrate vectors: ", err)
    }

    eng, err := engine.New(
        engine.WithStore(st),
        engine.WithVectorStore(pgvector.New(db, pgvector.WithDimensions(emb.Dimensions()))),
        engine.WithEmbedder(emb),
        engine.WithChunker(chunker.NewRecursiveChunker()),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer eng.Stop(ctx) // also closes db

    ctx = weave.WithTenant(ctx, "acme-corp")
    ctx = weave.WithApp(ctx, "support-bot")

    run(ctx, eng)
}
```

The metadata store and pgvector share one `*grove.DB`. `eng.Stop` closes the store, and with it the database.

## 2. Create a collection

```go
func run(ctx context.Context, eng *engine.Engine) {
    col := &collection.Collection{
        Name:          "product-docs",
        EmbeddingDims: 1536,
        ChunkSize:     256,
        ChunkOverlap:  32,
    }
    err := eng.CreateCollection(ctx, col)
    if errors.Is(err, weave.ErrCollectionAlreadyExists) {
        col, err = eng.GetCollectionByName(ctx, "product-docs")
    }
    if err != nil {
        log.Fatal("collection: ", err)
    }
```

Collection names are unique per tenant, so on a second run `CreateCollection` fails and the code picks up the existing collection instead.

## 3. Ingest documents

```go
    documents := []struct{ title, content string }{
        {
            title:   "Return Policy",
            content: "You can return an item within 30 days of purchase. Items must be in their original condition with all tags attached. Refunds take 5 to 7 business days.",
        },
        {
            title:   "Shipping Policy",
            content: "Standard shipping takes 5 to 7 business days. Expedited shipping takes 2 to 3 business days. We ship to all 50 US states and to 45 other countries.",
        },
        {
            title:   "Warranty",
            content: "Every product comes with a one-year limited warranty. It covers manufacturing defects but not accidental damage. Email support to file a claim.",
        },
    }

    for _, doc := range documents {
        res, err := eng.Ingest(ctx, &engine.IngestInput{
            CollectionID: col.ID,
            Title:        doc.title,
            Content:      doc.content,
        })
        switch {
        case errors.Is(err, weave.ErrDuplicateDocument):
            fmt.Printf("skipped %q: already ingested\n", doc.title)
            continue
        case err != nil:
            log.Printf("ingest %q: %v", doc.title, err)
            continue
        }
        fmt.Printf("ingested %q: %d chunks\n", doc.title, res.ChunkCount)
    }
```

The same content can't go into the same collection twice, so a rerun skips what's already there.

## 4. Retrieve relevant context

```go
    question := "How long do I have to return a product?"

    hits, err := eng.Retrieve(ctx, question,
        engine.WithCollection(col.ID),
        engine.WithTopK(5),
        engine.WithMinScore(0.3),
    )
    if err != nil {
        log.Fatal("retrieve: ", err)
    }
    for _, h := range hits {
        fmt.Printf("  [%.2f] %s\n", h.Score, h.Chunk.Content)
    }
```

Scores here are cosine similarity. A sensible `MinScore` depends on the model and your content, so print a few results before you pick one.

## 5. Assemble the prompt

```go
    assembled, err := eng.Assemble(ctx, hits, engine.AssembleParams{MaxTokens: 3000})
    if err != nil {
        log.Fatal("assemble: ", err)
    }

    prompt := fmt.Sprintf(`You are a helpful customer support assistant.

%s

Question: %s

Answer only from the context above, and cite sources with their [n] markers.`, assembled.Context, question)

    fmt.Println(prompt)

    for marker, pos := range assembled.Included {
        fmt.Printf("[%d] %s\n", marker+1, hits[pos].Chunk.DocumentID)
    }
}
```

Send `prompt` to the model of your choice. `assembled.Included` maps each `[n]` marker back to its hit, so you can turn the model's citations into links to the source documents.

## 6. Search several collections

When you have more than one collection, `HybridSearch` searches each and merges the hits by score:

```go
hits, err := eng.HybridSearch(ctx, question, &engine.HybridSearchParams{
    Collections: []id.CollectionID{col1ID, col2ID},
    TopK:        10,
    MinScore:    0.3,
})
```

Scores from different collections are only comparable when they came from the same embedder and vector store, which they do on one engine.
