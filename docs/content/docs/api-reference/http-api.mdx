title: HTTP API Reference
description: Complete reference for all 13 Weave REST endpoints for collections, documents, retrieval and search.
---

The Forge extension mounts these routes under its base path, `/weave` by default, so every path below starts with `/weave/v1`. Change the prefix with `base_path` or `extension.WithBasePath`. All bodies are JSON.

The routes take the tenant from the request context, where your middleware has to put it with `weave.WithTenant`. Without one, every route answers 403. With one, every route works inside that tenant: lists show only its rows, and another tenant's ID is a 404. See [HTTP API](/docs/subsystems/http-api#tenants).

## Collections

### `POST /weave/v1/collections`

Create a collection.

**Request**

```json
{
  "name": "product-docs",
  "description": "Product documentation",
  "embedding_model": "text-embedding-3-small",
  "embedding_dims": 1536,
  "chunk_strategy": "recursive",
  "chunk_size": 512,
  "chunk_overlap": 50,
  "metadata": { "domain": "support" }
}
```

Only `name` is required. Omitted `chunk_size`, `chunk_overlap`, `chunk_strategy` and `embedding_model` take the engine defaults (512, 50, `recursive`, `text-embedding-3-small`). `embedding_model`, `embedding_dims` and `chunk_strategy` are recorded and nothing more: the engine's configured embedder and chunker do the work.

**Response** `201 Created`

```json
{
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:00Z",
  "id": "col_01h455vbjdx6ycf56rnatbxqkh",
  "name": "product-docs",
  "description": "Product documentation",
  "tenant_id": "tenant-1",
  "app_id": "",
  "embedding_model": "text-embedding-3-small",
  "embedding_dims": 1536,
  "chunk_strategy": "recursive",
  "chunk_size": 512,
  "chunk_overlap": 50,
  "metadata": { "domain": "support" },
  "document_count": 0,
  "chunk_count": 0
}
```

`document_count` and `chunk_count` on a collection are never updated and stay at 0. Use the stats route for real counts.

A missing `name` is a 400. A name that already exists for the tenant is a 500.

---

### `GET /weave/v1/collections`

List collections, oldest first.

| Query param | Type | Description |
|-------------|------|-------------|
| `limit` | int | Maximum results. Default 50, capped at 1000. |
| `offset` | int | Results to skip |

**Response** `200 OK`: an array of the request tenant's collection objects.

---

### `GET /weave/v1/collections/:collectionId`

**Response** `200 OK`: a collection object. `400` for an ID that isn't a `col_` TypeID, `404` when there's no such collection.

---

### `DELETE /weave/v1/collections/:collectionId`

Deletes the collection's chunks, documents, vectors and then the collection.

**Response** `204 No Content`, or `404` when there's no such collection.

---

### `GET /weave/v1/collections/:collectionId/stats`

**Response** `200 OK`

```json
{
  "collection_id": "col_01h455vbjdx6ycf56rnatbxqkh",
  "collection_name": "product-docs",
  "document_count": 42,
  "chunk_count": 1204,
  "embedding_model": "text-embedding-3-small",
  "chunk_strategy": "recursive"
}
```

The counts are live: documents in any state, and every chunk.

---

### `POST /weave/v1/collections/:collectionId/reindex`

Re-embeds the chunks of every `ready` document with the engine's current embedder. The request is synchronous, so a large collection can take a while.

**Response** `204 No Content`, or `404` when the tenant has no such collection.

---

## Documents

### `POST /weave/v1/collections/:collectionId/documents`

Ingest one document. Runs the whole load, chunk, embed and store pipeline before it responds.

**Request**

```json
{
  "title": "Return Policy",
  "content": "Our return policy allows returns within 30 days...",
  "source": "policy.md",
  "source_type": "text/markdown",
  "metadata": { "category": "support" }
}
```

`content` is required. `source_type` only matters when the engine has a loader that supports it.

**Response** `201 Created`

```json
{
  "document_id": "doc_01h455vbjdx6ycf56rnatbxqki",
  "chunk_count": 12,
  "state": "ready"
}
```

Empty `content` is a 400. A collection the tenant doesn't have is a 404, and nothing is embedded. Content already in the collection and embedder or store failures are 500s.

---

### `POST /weave/v1/collections/:collectionId/documents/batch`

**Request**

```json
{
  "documents": [
    { "title": "Doc A", "content": "..." },
    { "title": "Doc B", "content": "..." }
  ]
}
```

Each document takes the same fields as the single ingest route. Any empty `content` fails the whole request with a 400 before anything is ingested.

**Response** `201 Created`: an array of ingest results, in order. Documents are ingested one at a time, and the first failure ends the request with an error. The documents before it stay ingested.

---

### `GET /weave/v1/collections/:collectionId/documents`

| Query param | Type | Description |
|-------------|------|-------------|
| `state` | string | `pending`, `processing`, `ready` or `failed` |
| `limit` | int | Maximum results. Default 50, capped at 1000. |
| `offset` | int | Results to skip |

**Response** `200 OK`: an array of document objects, oldest first. `404` when the tenant has no such collection.

---

### `GET /weave/v1/documents/:documentId`

**Response** `200 OK`

```json
{
  "created_at": "2026-01-15T10:30:00Z",
  "updated_at": "2026-01-15T10:30:05Z",
  "id": "doc_01h455vbjdx6ycf56rnatbxqki",
  "collection_id": "col_01h455vbjdx6ycf56rnatbxqkh",
  "tenant_id": "tenant-1",
  "title": "Return Policy",
  "source": "policy.md",
  "source_type": "text/markdown",
  "content_hash": "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08",
  "content_length": 1024,
  "chunk_count": 12,
  "metadata": { "category": "support" },
  "state": "ready"
}
```

`content_hash` is the hex SHA-256 of the raw content. `error` appears when `state` is `failed`.

---

### `DELETE /weave/v1/documents/:documentId`

Deletes the document's vectors, its chunks and the document.

**Response** `204 No Content`, or `404` when there's no such document.

## Retrieval

### `POST /weave/v1/collections/:collectionId/retrieve`

Semantic retrieval within one collection.

**Request**

```json
{
  "query": "What is the return policy?",
  "top_k": 5,
  "min_score": 0.3
}
```

`query` is required. Send `top_k`: when you leave it out the engine is asked for 0 results, the built-in vector stores turn that into 10, and the MMR retriever returns nothing. `default_top_k` isn't applied on this route, and anything above 1000 is cut to 1000. A `strategy` field is accepted and ignored. A collection the tenant doesn't have is a 404, and the query isn't embedded.

**Response** `200 OK`

```json
[
  {
    "chunk": {
      "id": "chk_01h455vbjdx6ycf56rnatbxqkj",
      "document_id": "doc_01h455vbjdx6ycf56rnatbxqki",
      "collection_id": "col_01h455vbjdx6ycf56rnatbxqkh",
      "tenant_id": "tenant-1",
      "content": "Our return policy allows returns within 30 days...",
      "index": 0,
      "start_offset": 0,
      "end_offset": 312,
      "token_count": 78,
      "metadata": {
        "chunk_index": "0",
        "collection_id": "col_01h455vbjdx6ycf56rnatbxqkh",
        "document_id": "doc_01h455vbjdx6ycf56rnatbxqki",
        "tenant_id": "tenant-1"
      },
      "created_at": "2026-01-15T10:30:05Z"
    },
    "score": 0.94,
    "hydrated": true
  }
]
```

Hits come back best first. `orphaned: true` marks a hit whose chunk is in the vector store but no longer in the metadata store.

---

### `POST /weave/v1/search`

Search across collections.

**Request**

```json
{
  "query": "refund timeline",
  "collections": ["col_01h455vbjdx6ycf56rnatbxqkh", "col_01h455vbjdx6ycf56rnatbxqkm"],
  "top_k": 10,
  "min_score": 0.3
}
```

With `collections`, each one is searched separately and the hits are merged, sorted by score and cut to `top_k`. Without it, one search runs over every collection of the request's tenant. `top_k` defaults to `default_top_k` here and is capped at 1000. `strategy` is accepted and ignored. If any collection in `collections` isn't the tenant's, the whole request is a 404 before anything is searched.

**Response** `200 OK`: an array of scored chunks, as for retrieve.

## Errors

400, 403 and 404 responses carry Forge's HTTP error body:

```json
{ "error": "content is required", "code": 400 }
```

| Status | When |
|--------|------|
| `400` | A malformed ID, a missing `name`, `content` or `query`, or an argument the engine refuses |
| `403` | The request has no tenant. The body says `weave: this request has no tenant`. It wins over every other error, so a malformed request without a tenant is a 403 too |
| `404` | The collection or document isn't there in the request's tenant, on every route that names one: get, delete, stats, reindex, ingest, list documents, retrieve, and search with `collections` |
| `500` | Anything else, including duplicate names or content, and embedder or store failures |

A 500 goes through Forge's error handling, which by default doesn't put the error text in the response.
