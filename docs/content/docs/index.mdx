Weave is a Go library for retrieval-augmented generation (RAG). You hand it documents, and it chunks the text, generates embeddings, writes the vectors to a vector store, then retrieves the closest chunks for a query and assembles them into prompt context with a token budget and `[n]` citation markers.

It's a library, not a service. You own `main`, the database connection and the process lifecycle. If you run [Forge](https://github.com/xraph/forge), the `extension` package mounts the same engine as a Forge extension with an HTTP API.

## What it does

- `engine.Ingest` runs one document through load, chunk, embed and store. `IngestBatch` runs a slice of them, one after another.
- `engine.Retrieve` embeds the query and searches the vector store, or hands off to a retriever you configure: similarity, MMR, hybrid (Reciprocal Rank Fusion) or a reranker wrapper. `HybridSearch` covers several collections at once.
- `engine.Assemble` turns the hits into one context string that fits a token budget, with a marker in front of each chunk.
- Documents live in named collections, each with its own chunk size, overlap and a recorded embedding model.
- The loader, chunker, embedder, retriever, vector store and metadata store are all Go interfaces.
- Metadata goes in PostgreSQL, SQLite, MongoDB or memory. Vectors go in pgvector, [Fabriq](https://github.com/xraph/fabriq) or memory.
- `weave.WithTenant` on the context stamps the tenant on everything you create and filters retrieval to it. See [multi-tenancy](/docs/concepts/multi-tenancy) for exactly what is and isn't scoped.
- You can hook into 14 lifecycle events (collections, ingestion, retrieval, deletes, reindexing and shutdown). Weave ships a metrics extension and a Chronicle audit bridge built on them.
- `extension.New` builds the engine, provides `*engine.Engine` in the DI container and mounts 13 routes under `/weave/v1`.

## Quick look

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/xraph/weave/chunker"
    "github.com/xraph/weave/collection"
    "github.com/xraph/weave/embedder"
    "github.com/xraph/weave/engine"
    "github.com/xraph/weave/store/memory"
    vsmemory "github.com/xraph/weave/vectorstore/memory"
)

func main() {
    ctx := context.Background()

    eng, err := engine.New(
        engine.WithStore(memory.New()),
        engine.WithVectorStore(vsmemory.New()),
        engine.WithEmbedder(embedder.NewOpenAIEmbedder(os.Getenv("OPENAI_API_KEY"))),
        engine.WithChunker(chunker.NewRecursiveChunker()),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer eng.Stop(ctx)

    col := &collection.Collection{Name: "handbook"}
    if err := eng.CreateCollection(ctx, col); err != nil {
        log.Fatal(err)
    }

    res, err := eng.Ingest(ctx, &engine.IngestInput{
        CollectionID: col.ID,
        Title:        "Leave policy",
        Content:      "Full-time staff get 25 days of paid leave a year.",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("ingested %s into %d chunks\n", res.DocumentID, res.ChunkCount)

    hits, err := eng.Retrieve(ctx, "How many vacation days do I get?",
        engine.WithCollection(col.ID),
        engine.WithTopK(3),
    )
    if err != nil {
        log.Fatal(err)
    }

    prompt, err := eng.Assemble(ctx, hits, engine.AssembleParams{MaxTokens: 1024})
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(prompt.Context)
}
```
