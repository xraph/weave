Everything lives in the one module, `github.com/xraph/weave`. The full API is on [pkg.go.dev](https://pkg.go.dev/github.com/xraph/weave).

## Core packages

### `github.com/xraph/weave`

| Export | Description |
|--------|-------------|
| `WithTenant(ctx, t)`, `WithApp(ctx, a)` | Put the tenant or app on a context |
| `TenantFromContext(ctx)`, `AppFromContext(ctx)` | Read them back (empty when unset) |
| `Config`, `DefaultConfig()` | Engine defaults |
| `ErrNoStore`, `ErrNoVectorStore`, `ErrNoEmbedder`, `ErrNoChunker` | A required component isn't configured |
| `ErrCollectionNotFound`, `ErrDocumentNotFound`, `ErrChunkNotFound` | Lookups that found nothing |
| `ErrCollectionAlreadyExists`, `ErrDuplicateDocument` | Name or content conflicts |
| `ErrEmptyContent`, `ErrMigrationFailed` | Ingest with no content, a failed store migration |
| `ScoreKind`, `ComponentInfo`, `Describer` | How components describe themselves and their scores |

[Error handling](/docs/concepts/errors) lists every sentinel.

### `github.com/xraph/weave/engine`

| Export | Description |
|--------|-------------|
| `New(...Option) (*Engine, error)` | Create an engine |
| `WithStore`, `WithVectorStore`, `WithEmbedder`, `WithChunker`, `WithLoader`, `WithRetriever`, `WithExtension`, `WithLogger`, `WithConfig` | Engine options |
| `Engine.CreateCollection`, `GetCollection`, `GetCollectionByName`, `ListCollections`, `CountCollections`, `UpdateCollection`, `DeleteCollection`, `CollectionStats` | Collections |
| `Engine.Ingest`, `IngestBatch` | Ingestion |
| `Engine.GetDocument`, `ListDocuments`, `CountDocuments`, `DeleteDocument` | Documents |
| `Engine.GetChunk`, `ListChunks`, `CountChunks` | Chunks (`ListChunks` needs a document or collection ID) |
| `Engine.Retrieve`, `HybridSearch`, `RetrieveCompare` | Retrieval |
| `Engine.Assemble`, `AssembleRefs` | Context assembly |
| `Engine.ReindexCollection` | Re-embed a collection |
| `Engine.Components`, `DescribeExtensions`, `Config`, `Store`, `Logger`, `Extensions` | Introspection |
| `Engine.Start`, `Stop`, `Health` | Lifecycle. `Start` does nothing yet; `Stop` fires `OnShutdown` and closes the store. |
| `WithCollection`, `WithTopK`, `WithMinScore`, `WithTenantID`, `WithTenantFilter`, `WithStrategy` | Retrieve options (`WithStrategy` is ignored) |
| `IngestInput`, `IngestResult`, `ScoredChunk`, `HybridSearchParams`, `AssembleParams`, `AssembledContext`, `CollectionUpdate`, `CompareParams`, `CompareResult` | Parameter and result types |

## Interface packages

### `github.com/xraph/weave/chunker`

```go
type Chunker interface {
    Chunk(ctx context.Context, text string, opts *Options) ([]ChunkResult, error)
}
```

### `github.com/xraph/weave/embedder`

```go
type Embedder interface {
    Embed(ctx context.Context, texts []string) ([]EmbedResult, error)
    Dimensions() int
}
```

### `github.com/xraph/weave/loader`

```go
type Loader interface {
    Load(ctx context.Context, reader io.Reader) (*LoadResult, error)
    Supports(mimeType string) bool
}
```

### `github.com/xraph/weave/retriever`

```go
type Retriever interface {
    Retrieve(ctx context.Context, query string, opts *Options) ([]Result, error)
}

type Reranker interface {
    Rerank(ctx context.Context, query string, documents []string) ([]float64, error)
}
```

### `github.com/xraph/weave/store`

```go
type Store interface {
    document.Store
    collection.Store
    chunk.Store
    Migrate(ctx context.Context) error
    Ping(ctx context.Context) error
    Close() error
}
```

### `github.com/xraph/weave/vectorstore`

```go
type VectorStore interface {
    Upsert(ctx context.Context, entries []Entry) error
    Search(ctx context.Context, vector []float32, opts *SearchOptions) ([]SearchResult, error)
    Delete(ctx context.Context, ids []string) error
    DeleteByMetadata(ctx context.Context, filter map[string]string) error
}
```

## Extension packages

### `github.com/xraph/weave/ext` and `github.com/xraph/weave/plugins`

The same lifecycle hook interfaces in both: `Extension`, `CollectionCreated`, `CollectionDeleted`, `IngestStarted`, `IngestChunked`, `IngestEmbedded`, `IngestCompleted`, `IngestFailed`, `RetrievalStarted`, `RetrievalCompleted`, `RetrievalFailed`, `DocumentDeleted`, `ReindexStarted`, `ReindexCompleted`, `Shutdown`. Each also has a `Registry`.

### `github.com/xraph/weave/observability`

```go
func NewMetricsExtension() *MetricsExtension
func NewMetricsExtensionWithFactory(factory gu.MetricFactory) *MetricsExtension
```


## Implementations

| Constructor | Implements | Notes |
|-------------|-----------|-------|
| `store/memory.New()` | `store.Store` | In memory |
| `store/postgres.New(db *grove.DB)` | `store.Store` | PostgreSQL on Grove |
| `store/sqlite.New(db *grove.DB)` | `store.Store` | SQLite on Grove |
| `store/mongo.New(db *grove.DB)` | `store.Store` | MongoDB on Grove |
| `vectorstore/memory.New()` | `vectorstore.VectorStore` | Brute-force cosine similarity |
| `vectorstore/pgvector.New(db, opts...)` | `vectorstore.VectorStore` | PostgreSQL with pgvector; you create the table |
| `vectorstore/fabriq.New(vq, opts...)` | `vectorstore.VectorStore` | Fabriq vector plane (package `fabriqvec`) |
| `chunker.NewRecursiveChunker()` | `chunker.Chunker` | Separator-based |
| `chunker.NewFixedChunker()` | `chunker.Chunker` | Fixed character windows |
| `chunker.NewSlidingChunker()` | `chunker.Chunker` | Sliding window |
| `chunker.NewSemanticChunker()` | `chunker.Chunker` | Sentence groups |
| `chunker.NewCodeChunker()` | `chunker.Chunker` | Code block boundaries |
| `embedder.NewOpenAIEmbedder(apiKey, opts...)` | `embedder.Embedder` | OpenAI or any compatible endpoint |
| `embedder.NewLocalEmbedder(dims)` | `embedder.Embedder` | Placeholder, returns `ErrNotImplemented` |
| `retriever.NewSimilarityRetriever(vs, emb, store)` | `retriever.Retriever` | Plain vector search |
| `retriever.NewMMRRetriever(vs, emb, lambda)` | `retriever.Retriever` | Maximal Marginal Relevance |
| `retriever.NewHybridRetriever(retrievers...)` | `retriever.Retriever` | Reciprocal Rank Fusion of other retrievers |
| `retriever.NewRerankerRetriever(base, reranker)` | `retriever.Retriever` | Reorders with your `Reranker` |
| `loader.NewTextLoader()`, `NewMarkdownLoader()`, `NewHTMLLoader()`, `NewCSVLoader()`, `NewJSONLoader(fields...)` | `loader.Loader` | Format loaders |
| `loader.NewURLLoader(delegate)` | none | Call `LoadURL`; not a `loader.Loader` |
| `loader.NewDirectoryLoader(loaders...)` | `loader.Loader` | Call `LoadDir`; `Supports` is always false |
| `extension.New(opts...)` | `forge.Extension` | Forge integration |

## ID package

### `github.com/xraph/weave/id`

```go
func NewCollectionID() ID
func NewDocumentID() ID
func NewChunkID() ID

func ParseCollectionID(s string) (ID, error)
func ParseDocumentID(s string) (ID, error)
func ParseChunkID(s string) (ID, error)
```

`CollectionID`, `DocumentID` and `ChunkID` are aliases for `ID`, so the compiler won't stop you mixing them up; the `Parse*ID` functions check the prefix. See [identity](/docs/concepts/identity).
