---
title: MongoDB Store
description: Document-oriented metadata store using Grove with mongodriver for MongoDB.
---

The `store/mongo` package keeps collections, documents and chunks in MongoDB through [Grove](https://github.com/xraph/grove) and its `mongodriver`.

## Setup

```go
import (
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/mongodriver"

    mongostore "github.com/xraph/weave/store/mongo"
)

mdb := mongodriver.New()
if err := mdb.Open(ctx, "mongodb://localhost:27017", mongodriver.WithDatabase("weave")); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(mdb)
if err != nil {
    log.Fatal(err)
}

st := mongostore.New(db)
if err := st.Migrate(ctx); err != nil {
    log.Fatal(err)
}
```

## Migrations

`Migrate` creates the three MongoDB collections and their indexes:

| Collection | Holds | Indexes |
|------------|-------|---------|
| `weave_collections` | Collections | unique `(tenant_id, name)`, `tenant_id`, `created_at` |
| `weave_documents` | Documents | unique `(collection_id, content_hash)`, `(collection_id, state)`, `tenant_id`, `created_at` |
| `weave_chunks` | Chunk text and offsets | `(document_id, index)`, `collection_id` |

It runs each migration's `Up` directly. The same migrations are exported as `mongostore.Migrations`, a Grove migration group, for Grove's orchestrator.

The unique indexes give you `weave.ErrCollectionAlreadyExists` and `weave.ErrDuplicateDocument`, the same as the SQL stores.

## Pairing with a vector store

MongoDB holds only the metadata. Pair it with any vector store, for example pgvector in a Postgres database:

```go
eng, err := engine.New(
    engine.WithStore(mongostore.New(db)),
    engine.WithVectorStore(pgvector.New(pgDB)), // a separate *grove.DB on Postgres
    engine.WithEmbedder(emb),
    engine.WithChunker(chunker.NewRecursiveChunker()),
)
```

## Tenancy

Documents in `weave_collections` carry `tenant_id` and `app_id`, and documents and chunks carry `tenant_id`. Queries filter on the tenant only when a list filter's `Tenant` is set, as with every store; see [multi-tenancy](/docs/concepts/multi-tenancy).

## Lifecycle

| Method | Behaviour |
|--------|-----------|
| `Migrate(ctx)` | Creates the collections and indexes |
| `Ping(ctx)` | Pings the server |
| `Close()` | Closes the `*grove.DB` |
