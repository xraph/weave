## Prerequisites

- Go 1.26 or later
- A Go module (`go mod init`)
- An OpenAI API key, or any OpenAI-compatible embeddings endpoint

## Install

```bash
go get github.com/xraph/weave@latest
```

## Step 1: Create the engine

The engine needs four things before it can ingest: a metadata store, a vector store, an embedder and a chunker. Nothing is filled in for you. If one is missing, `Ingest` returns `weave.ErrNoStore`, `ErrNoVectorStore`, `ErrNoEmbedder` or `ErrNoChunker`.

For development, use the in-memory stores:

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/xraph/weave"
    "github.com/xraph/weave/chunker"
    "github.com/xraph/weave/collection"
    "github.com/xraph/weave/embedder"
    "github.com/xraph/weave/engine"
    "github.com/xraph/weave/store/memory"
    vsmemory "github.com/xraph/weave/vectorstore/memory"
)

func main() {
    ctx := context.Background()

    eng, err := engine.New(
        engine.WithStore(memory.New()),
        engine.WithVectorStore(vsmemory.New()),
        engine.WithEmbedder(embedder.NewOpenAIEmbedder(os.Getenv("OPENAI_API_KEY"))),
        engine.WithChunker(chunker.NewRecursiveChunker()),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer eng.Stop(ctx)

    // Steps 2 to 6 go here.
}
```

`NewOpenAIEmbedder` uses `text-embedding-3-small` unless you pass `embedder.WithOpenAIModel`. Point it at another OpenAI-compatible server with `embedder.WithOpenAIBaseURL`.

## Step 2: Put a tenant on the context

```go
ctx = weave.WithTenant(ctx, "acme")
ctx = weave.WithApp(ctx, "support-bot")
```

This is optional. When it's there, `CreateCollection` records the tenant and app on the collection, `Ingest` stamps the tenant on the document and its chunks, and `Retrieve` only searches vectors with that tenant. Reads by ID and list calls don't check it, so read [multi-tenancy](/docs/concepts/multi-tenancy) before you rely on it for isolation.

## Step 3: Create a collection

A collection holds documents that share chunk settings:

```go
col := &collection.Collection{
    Name:         "handbook",
    ChunkSize:    256,
    ChunkOverlap: 32,
}
if err := eng.CreateCollection(ctx, col); err != nil {
    log.Fatal(err)
}
fmt.Println("created collection", col.ID)
```

`CreateCollection` fills in the ID (`col_...`) and, for any field you leave at zero, the engine defaults: chunk size 512, overlap 50, strategy `recursive` and embedding model `text-embedding-3-small`. The model and strategy are only recorded. The embedder and chunker you passed to `engine.New` are what actually run. A second collection with the same name under the same tenant fails with `weave.ErrCollectionAlreadyExists`.

## Step 4: Ingest a document

```go
res, err := eng.Ingest(ctx, &engine.IngestInput{
    CollectionID: col.ID,
    Title:        "Leave policy",
    Source:       "handbook/leave.md",
    Content: "Full-time staff get 25 days of paid leave a year. " +
        "Unused days carry over until the end of March. " +
        "Requests longer than two weeks need approval from your manager.",
})
if err != nil {
    log.Fatal(err)
}
fmt.Printf("ingested %s: state=%s chunks=%d\n", res.DocumentID, res.State, res.ChunkCount)
```

`Ingest` is synchronous. It chunks the content with the collection's size and overlap, embeds every chunk in one call, writes the chunks to the metadata store and the vectors to the vector store, then marks the document `ready`. Ingesting the same content into the same collection a second time fails with `weave.ErrDuplicateDocument`.

## Step 5: Retrieve relevant chunks

```go
hits, err := eng.Retrieve(ctx, "How many vacation days do I get?",
    engine.WithCollection(col.ID),
    engine.WithTopK(3),
)
if err != nil {
    log.Fatal(err)
}
for _, h := range hits {
    fmt.Printf("[%.2f] %s\n", h.Score, h.Chunk.Content)
}
```

You get `[]engine.ScoredChunk`, best first. Each hit has:

| Field | What it holds |
|-------|---------------|
| `Chunk` | The `*chunk.Chunk`, read back from the metadata store: `Content`, `DocumentID`, `CollectionID`, `Index`, offsets, `Metadata` |
| `Score` | Cosine similarity with the in-memory and pgvector stores |
| `Hydrated` | `true` when `Chunk` was read back from the metadata store |
| `Orphaned` | `true` when the vector store returned a chunk the metadata store no longer has |

With no `WithTopK`, you get the engine's `DefaultTopK` (10).

## Step 6: Build prompt context

```go
prompt, err := eng.Assemble(ctx, hits, engine.AssembleParams{MaxTokens: 1024})
if err != nil {
    log.Fatal(err)
}
fmt.Println(prompt.Context)
```

`Context` starts with `Relevant context:` and puts a `[1]`, `[2]` marker in front of each chunk, in rank order, until the token budget runs out (4096 when you pass zero). `prompt.Included[n-1]` is the position in `hits` that marker `[n]` came from, so you can show citations next to the answer. Tokens are estimated at four characters each.

## Batch ingest

```go
results, err := eng.IngestBatch(ctx, []*engine.IngestInput{
    {CollectionID: col.ID, Title: "Expenses", Content: "Submit receipts within 30 days."},
    {CollectionID: col.ID, Title: "Remote work", Content: "You can work remotely two days a week."},
})
if err != nil {
    log.Fatal(err)
}
fmt.Printf("ingested %d documents\n", len(results))
```

`IngestBatch` calls `Ingest` for each input in order and stops at the first error, returning the results it already has. It doesn't run documents in parallel: the `IngestConcurrency` setting exists in the config but nothing reads it yet.

## Switch to PostgreSQL

Open one `*grove.DB` and share it between the metadata store and pgvector:

```go
import (
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"

    "github.com/xraph/weave/store/postgres"
    "github.com/xraph/weave/vectorstore/pgvector"
)

pgdb := pgdriver.New()
if err := pgdb.Open(ctx, os.Getenv("DATABASE_URL")); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(pgdb)
if err != nil {
    log.Fatal(err)
}

st := postgres.New(db)
if err := st.Migrate(ctx); err != nil {
    log.Fatal(err)
}

eng, err := engine.New(
    engine.WithStore(st),
    engine.WithVectorStore(pgvector.New(db)),
    engine.WithEmbedder(embedder.NewOpenAIEmbedder(os.Getenv("OPENAI_API_KEY"))),
    engine.WithChunker(chunker.NewRecursiveChunker()),
)
```

`Migrate` creates the metadata tables. Nothing creates the pgvector side: you have to create the `vector` extension and the `weave_vectors` table yourself before the first ingest. The [PostgreSQL store](/docs/stores/postgres#pgvector) page has the table definition.
