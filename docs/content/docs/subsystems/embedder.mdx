---
title: Embedder
description: The Embedder interface and built-in implementations for generating vector embeddings.
---

The embedder turns text into vectors. The engine calls it during ingestion (once per document, with every chunk's text) and during retrieval (with the query), plus once per document on a reindex.

## Embedder interface

```go
// package embedder
type Embedder interface {
    // Embed generates embeddings for a batch of texts.
    Embed(ctx context.Context, texts []string) ([]EmbedResult, error)

    // Dimensions returns the vector dimensionality.
    Dimensions() int
}

type EmbedResult struct {
    Vector     []float32 `json:"vector"`
    TokenCount int       `json:"token_count"`
}
```

Set it with `engine.WithEmbedder(e)`. Without one, `Ingest` and `ReindexCollection` return `weave.ErrNoEmbedder`, and `Retrieve` fails unless you configured a retriever.

## OpenAI embedder

```go
import "github.com/xraph/weave/embedder"

emb := embedder.NewOpenAIEmbedder(os.Getenv("OPENAI_API_KEY"))
// model text-embedding-3-small, emb.Dimensions() == 1536
```

`NewOpenAIEmbedder(apiKey string, opts ...OpenAIOption)` posts to `{baseURL}/v1/embeddings`. Its options:

| Option | Default | Description |
|--------|---------|-------------|
| `WithOpenAIModel(model)` | `text-embedding-3-small` | Model name sent with each request |
| `WithOpenAIDimensions(n)` | `1536` | What `Dimensions()` reports |
| `WithOpenAIBaseURL(url)` | `https://api.openai.com` | Base URL, without `/v1` |
| `WithOpenAIClient(c)` | `http.DefaultClient` | HTTP client |

`WithOpenAIDimensions` isn't sent to the API. It only sets what `Dimensions()` returns, so when you change the model, set it to that model's real output size:

```go
emb := embedder.NewOpenAIEmbedder(
    apiKey,
    embedder.WithOpenAIModel("text-embedding-3-large"),
    embedder.WithOpenAIDimensions(3072),
)
```

Any server that speaks the OpenAI embeddings API works through the base URL, for example a local Ollama:

```go
emb := embedder.NewOpenAIEmbedder(
    "unused",
    embedder.WithOpenAIBaseURL("http://localhost:11434"),
    embedder.WithOpenAIModel("nomic-embed-text"),
    embedder.WithOpenAIDimensions(768),
)
```

The whole batch goes out in one request, so very large documents can hit the provider's input limits. `TokenCount` on each result is the response's total token usage split across the inputs: each gets an equal share and the first few one token more, so the counts add up to what the API reported.

A status other than 200 comes back as `*embedder.StatusError`, which carries `StatusCode`. Use `errors.As` to tell a rate limit (429) from a bad key (401).

Each call gets an OpenTelemetry client span named `POST` with the server's host and port and the response status. It never records the URL's path or query, any userinfo in the base URL, the key or the texts, and it drops the caller's baggage before the request leaves. The client you pass with `WithOpenAIClient` is traced the same way, so don't hand it a transport that is traced already. See [observability](/docs/subsystems/observability).

## Nexus embedder

If your app already runs a [nexus](https://github.com/xraph/nexus) gateway, you can send embeddings through it. Nexus records the spend on the same usage rows and budgets as your chat traffic, and the provider's key never leaves nexus.

It ships as its own module, so the root `github.com/xraph/weave` never pulls in nexus:

```bash
go get github.com/xraph/weave/embedder/nexus
```

```go
import (
    weavenexus "github.com/xraph/weave/embedder/nexus"
)

// nexusExt is nexus's Forge extension. Pass its Gateway method, not its result.
emb := weavenexus.New(nexusExt.Gateway, "text-embedding-3-small", 1536,
    weavenexus.WithProvider("knowledge"),
)
eng, err := engine.New(engine.WithEmbedder(emb) /* , ... */)
```

`New(gw func() *nexus.Gateway, model string, dimensions int, opts ...Option)` doesn't call `gw`. The first `Embed` does, and keeps the first gateway it gets back, so you can build the embedder before nexus has started. Until then `Embed` returns `weavenexus.ErrGatewayUnavailable`: while `gw` answers nil, and while the gateway it answered isn't initialized (the error also matches `nexus.ErrNotInitialized`). Both clear once nexus starts, so it's safe to retry.

| Option | Default | Description |
|--------|---------|-------------|
| `WithProvider(name)` | none, nexus routes by model | The registered nexus provider every request goes to |
| `WithTenantMapper(fn)` | the weave tenant, unchanged | Turns the weave tenant into the nexus tenant the call is charged to |
| `WithBatchSize(n)` | `256` | Most texts in one nexus request |

### Pick the provider

Pass `WithProvider` whenever more than one nexus provider could serve the model. Without it nexus routes by model name, and a chat provider that also lists `text-embedding-3-small` can win, so the call goes out with that provider's key and base URL. With a name, nexus calls that provider or refuses the request. It never swaps in another one.

### Tenants and who pays

Every call needs a weave tenant on the context (`weave.WithTenant`). Without one, `Embed` returns `weave.ErrTenantRequired` before it calls nexus, so no embedding ever goes out without someone to charge it to.

Who pays depends on what's on the context:

- If your middleware set a nexus tenant with nexus's `pipeline.WithTenantID`, the call is charged to that one and the mapper isn't called.
- Otherwise the weave tenant goes through `WithTenantMapper` and the result is sent as the request's `TenantID`. A mapper that returns `""` gives `weave.ErrTenantRequired`.

The default mapper passes the weave tenant straight through, which only works when your weave tenants are nexus tenant IDs (`tenant_...`). If they're something else, such as workspace IDs, pass a mapper. The nexus tenant has to exist and be active in nexus: nexus refuses an ID it can't parse with `middlewares.ErrInvalidIdentity` and an unknown one as forbidden, and `Embed` returns both wrapped.

### Dimensions

Every request asks nexus for exactly `dimensions` numbers per vector, so you can store a shorter vector than the model's native size (pgvector indexes up to 2000). That only works with a model that can shorten its vectors, and on OpenAI's own endpoint that means `text-embedding-3-small` or `text-embedding-3-large`. Nexus's `openai` provider knows this and refuses anything else there, `text-embedding-ada-002` included, even at its native 1536: you get an error wrapping `middlewares.ErrDimensionsUnsupported`, and nexus never calls OpenAI. Nexus's `opencompat` provider says yes for every model and sends the width along, so the endpoint decides, and OpenAI's endpoint rejects it for ada-002 with an error of its own.

Each response is still checked. A vector of the wrong length is `weave.ErrDimensionMismatch` with the model and both sizes in the message (nexus usually catches it first, and its `middlewares.ErrDimensionsMismatch` stays in the chain), and a response with fewer or more vectors than inputs is an error too.

Nexus reports usage per request, so `TokenCount` is split across the inputs the way the OpenAI embedder splits it. The embedder drops the caller's OpenTelemetry baggage before it calls nexus, and it sets no usage metadata.

## Local embedder

`embedder.NewLocalEmbedder(dimensions int)` exists, but it's a placeholder. Every `Embed` call returns `embedder.ErrNotImplemented`. Until a local model lands, run an OpenAI-compatible server and use the OpenAI embedder against it, or write your own `Embedder`.

## Matching the embedder to the collection

A collection's `EmbeddingModel` and `EmbeddingDims` are stored for your reference. They don't pick or configure the embedder: every collection on an engine is embedded by that engine's one embedder. Keep the embedder, the recorded model and your vector column's dimension in step yourself.

If you switch models, call `eng.ReindexCollection(ctx, colID)` to re-embed every chunk of the collection's `ready` documents with the engine's current embedder.

## Custom embedder

```go
type MyEmbedder struct {
    client myMLClient
    dims   int
}

func (e *MyEmbedder) Embed(ctx context.Context, texts []string) ([]embedder.EmbedResult, error) {
    vecs, err := e.client.Embed(ctx, texts)
    if err != nil {
        return nil, err
    }
    results := make([]embedder.EmbedResult, len(vecs))
    for i, v := range vecs {
        results[i] = embedder.EmbedResult{Vector: v}
    }
    return results, nil
}

func (e *MyEmbedder) Dimensions() int { return e.dims }
```

Return exactly one result per input, in input order. The engine pairs `results[i]` with chunk `i`, and a short slice makes ingest panic on the index.
