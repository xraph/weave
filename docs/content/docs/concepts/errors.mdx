## Sentinel errors

The root package defines sentinel errors. The engine and stores wrap them with `%w`, so check them with `errors.Is`:

```go
import (
    "errors"

    "github.com/xraph/weave"
)

_, err := eng.Ingest(ctx, input)
switch {
case errors.Is(err, weave.ErrCollectionNotFound):
    // no collection with that ID
case errors.Is(err, weave.ErrDuplicateDocument):
    // this content is already in the collection
}
```

| Error | Returned when |
|-------|---------------|
| `weave.ErrTenantRequired` | The context has no tenant (see [multi-tenancy](/docs/concepts/multi-tenancy)). Every store call but `Migrate`, `Ping` and `Close` returns it before touching the database |
| `weave.ErrNoStore` | An operation needs the metadata store and none is configured |
| `weave.ErrNoVectorStore` | `Ingest` or `ReindexCollection` without a vector store |
| `weave.ErrNoEmbedder` | `Ingest` or `ReindexCollection` without an embedder |
| `weave.ErrNoChunker` | `Ingest` without a chunker |
| `weave.ErrEmptyContent` | `Ingest` with empty `Content` |
| `weave.ErrCollectionNotFound` | No collection with that ID in the context tenant (from get, update, delete, stats, ingest, and creating a document in it). Another tenant's collection gets this too |
| `weave.ErrDocumentNotFound` | No document with that ID in the context tenant, including when you create chunks on it |
| `weave.ErrChunkNotFound` | No chunk with that ID in the context tenant |
| `weave.ErrCollectionAlreadyExists` | A collection with that name already exists for the tenant, on create or rename |
| `weave.ErrDuplicateDocument` | A document with the same content hash is already in the collection |
| `weave.ErrDocumentAlreadyExists` | A document with that ID already exists (in-memory store) |
| `weave.ErrMigrationFailed` | A store's `Migrate` failed |
| `weave.ErrInvalidArgument` | `UpdateCollection` with a blank name, `ListChunks` with neither a document nor a collection ID, a list or count filter whose deprecated `Tenant` differs from the context tenant, a create whose `TenantID` differs from it, a chunk whose collection isn't its document's, or `GetCollectionByName` on a store naming another tenant |

`ErrStoreClosed`, `ErrIngestJobNotFound`, `ErrInvalidState`, `ErrDimensionMismatch` and `ErrIngestInterrupted` are declared but nothing returns them yet.

`Retrieve` with neither a retriever nor an embedder and vector store returns a plain error (`weave: no retriever or embedder+vectorstore configured`), not a sentinel.

`embedder.ErrNotImplemented` comes from `embedder.LocalEmbedder`, which isn't implemented.

## Failed ingests

A failure during ingest leaves the document in the store with `State` set to `failed` and the error text in `Error`:

```go
doc, err := eng.GetDocument(ctx, docID)
if err == nil && doc.State == document.StateFailed {
    fmt.Println("ingestion failed:", doc.Error)
}
```

`Ingest` also returns the error itself, wrapped as `weave: ingest failed: ...`, together with an `IngestResult` holding the document ID.

## Store and provider errors

Errors from the database, the embedder or the vector store come back wrapped with context (`weave: search: ...`, `weave: openai embed: status 429`), so `errors.As` still finds driver-specific types underneath.

## Hook errors

Errors returned by lifecycle hooks are logged at warn level and never reach the caller. See [extension system](/docs/subsystems/plugins#error-handling).
